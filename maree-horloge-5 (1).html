Clé API

Les données de marée proviennent de l'API gratuite api-maree.fr (composantes harmoniques IFREMER / PREVIMER). Une clé personnelle gratuite est nécessaire — inscription sur api-maree.fr/register, puis colle ta clé ici.

Le vent provient d'Open-Meteo (gratuit, sans clé) et nécessite les coordonnées du site ; s'il n'y en a pas, l'info vent reste masquée. Le coefficient de marée est une estimation basée sur le marnage observé, pas une donnée officielle du SHOM.
